# 产品与交互规格

这是当前已确认的行为合同，不表示所有平台和真实场景已验收。具体交付与平台差异见 [当前状态](CURRENT_STATUS.md)、[同步清单](coordination/app-sync-backlog.md)。公式和算法不在此重复定义。

## 首页、检测、趋势与设置

底部导航为首页、检测、趋势、任务；海缸管理和其他配置由设置进入。各页按当前海缸隔离，停用指标不删除记录和目标。

- 首页显示动画鱼缸、当前海缸概览、确认记录生成的维护建议与本日未完成事项。每个启用参数的柱状图每屏约五次，左右滑动查看历史，初始定位最新；只画插值或单值，范围未填插值保留空位。
- 鱼类档案支持九种已选内置立绘和自定义品种/图片；数量、入缸日期按缸保存，动画最多显示 24 条但不截断库存。鱼完整尺寸不越界，头朝向跟随水平速度，日常刷新不重置运动状态。
- 所有启用参数支持手动检测、范围/单值、时间、备注、目标和历史编辑。NO3/PO4 支持额外可空插值；编辑人工结果不覆盖原始算法结果。
- 检测计时支持 3/5/10 分钟快捷项，按海缸/参数保存 10 秒至 60 分钟默认值。计时开始锁定时长；暂停可继续，重置后可修改。NO3/PO4 跳过或结束计时进入对应拍照流程；退出检测计时须清理相应状态和通知，不新增正式记录。
- 拍照结果先复核，可修改范围及插值后选择记录或放弃；没有可用算法建议仍允许手动录入。详见 [拍照规范](IMAGE_ESTIMATION.md)。
- 趋势详情保留目标范围、历史范围与插值。NO3/PO4 折线左右滑动；紫色范围线只在下限不等于上限时显示，并在两端标数值；绿色插值/单值各标一次，跨过没有插值的范围记录连到下一个有效点，不伪造中点。
- 趋势检测记录可折叠，默认十条；独立列表最高 480px，滚到底每次追加十条，并保留加载按钮。切换海缸/参数或折叠后重置；卡片下方只显示日期，备注在数据和编辑页保留。

## 任务的不同语义

| 类型 | 发生规则 | 完成/编辑与历史 |
| --- | --- | --- |
| 旧 App 周期任务 | 无可靠原始开始日，沿用旧操作时间推进 | 编辑后转固定日期规则，原事件保留 |
| 新建/编辑日期周期 | 按固定开始日与间隔计算；只展开所见日期 | 完成/跳过/恢复/稍后仅影响所选发生日；原任务 ID 和既有逐日记录保留 |
| PO4/KH 降低/提升计划 | 有限连续日程，每日先复测再决定执行 | 同缸同药剂覆盖只替换新开始日及以后，之前历史不变；停止一日停止当天及后续 |
| 每日平衡补液周期 | 按配方可用天数生成虚拟每日状态；目前仅网页 | 平日显示在已完成，补液日转待处理；确认续配才替换后续周期，规则见滴定规范 |

日期周期可从过去、今天或未来开始；过去开始时，今天之前符合间隔的日期默认为完成，可逐日恢复。任务右上角编辑预填原值，不能创建新规则替代原任务而遗失处理历史。

首页展示本日实际发生且未完成/未跳过的事项；同一 PO4/KH 有限计划按总计划合并展示与计数，底层逐日记录不变。网页新增补液周期逾期后持续进入本日待处理，不使所有旧任务变成跨日待办。

任务月历为周一开始的六周视图，可翻月、按日操作；长说明折叠。完成主按钮明确，稍后与跳过/停止分组。跳过或停止的事项从当日待办和日历隐藏，处理历史保留。

任务页“全部”展示仍运行的周期规则与仍有待处理天数的有限总计划；周期规则自身不进入待处理，实际发生项仍进入日历和首页。已完成记录按日期查看：网页版已随补液功能改为所选日期，App 该变化随 WEB-005 待同步。自动滴定发生项没有普通“恢复未完成”或跳过按钮。

## 计算与通知

- 新 PO4/KH 计划先校验输入及当前缸目标，再检测重复计划。三项选择为仅计算、不覆盖；取消；限定日期覆盖。预览和取消不写入或删除任务/历史，保存时重新检查相关边界。
- 稳定滴定按实际泵量及未取整天数配制；可编辑总体积默认 500 mL。主天数取整、括号三位有效数字。补液与残液详见 [滴定规范](MAINTENANCE_DOSING_CALCULATOR.md)。
- 常规建议根据用户目标与确认记录产生，保留 [规则依据](ADVICE_RULES.md)；理论加药计划与常规建议是独立入口。
- 网页提醒默认关闭，仅网页打开时生效；不能声称浏览器关闭后仍有手机系统通知。App 通知权限不随备份迁移，提醒总开关不删除任务。新日期周期目前预排近两次实际发生日，打开/恢复/修改任务后补排，不宣称无限后台排程。

## 简洁与数据保护

保留必要输入、即时错误原因、保存/删除/覆盖等实际操作；不要恢复已删的已阅读声明、取色确认勾选、下载取色记录和重复长提示。拍照主结果只留“仅供参考”；具体质量拒绝原因保留简短一条。危险覆盖/恢复展示实际影响并确认；归档、停用和跨缸编辑须保护历史。通知或相机拒绝时提供可继续操作的降级路径。
