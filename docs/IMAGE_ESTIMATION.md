# NO3 / PO4 拍照辅助估算规范

本文件维护当前辅助比色合同及真实样本验收边界。功能已接入网页与 App，算法效果仍待独立验证；主界面按用户要求只保留“仅供参考”，不增加冗余声明或勾选。

## 当前操作与输出

1. 用户拍照或选择照片；完整色卡和测试液尽量同框，避免遮挡、强反光、阴影和有色灯光，按试剂要求显色。
2. 用户以顺/逆时针 90° 将照片实际旋转到文字朝上、两行四列。旋转像素后清空旧选区和结果，再框选完整色卡及液体；原图不被覆盖。
3. 按固定模板自动提取八个色块，可逐块重框。数值来自预设模板，不执行数字 OCR，也不保证自动找到任意色卡或瓶子。
4. 分别给出“颜色更接近哪档”“候选范围”“插值参考值”；各项可单独成功或拒绝。范围失败会阻断依赖它的插值，但不强制清除仍可用的最近档。
5. 用户可修改范围和可空插值，选择记录或放弃；只有确认记录进入历史及建议。没有插值不补中点。

| 模板 | 从左到右、从上到下的八块浓度（mg/L） |
| --- | --- |
| NO3 | 100、50、25、10；10、5、1、0 |
| PO4 | 3、1、0.5、0.25；0、0.03、0.1、0.25 |

两处重复色档也是图像质量对照，不能简单删为七个取色框。模板/色卡版本不匹配时需用户修正或手动录入，不自动猜浓度。

## 当前取色与比较

实现入口为网页 [color-analysis.ts](../web-demo/app/color-match/color-analysis.ts) 和 App [card_color_match.dart](../app/lib/features/image_estimation/domain/card_color_match.dart)。

- 每个选区抽样像素，过滤严重截断高光、过暗与透明像素；用 RGB 各通道中位数代表区域，不是所有像素的简单平均。
- 色块在模板格中心附近搜索候选框，综合区域颜色离散程度和被过滤比例选择；同浓度重复档的代表 RGB 在比较阶段汇总。
- 将 sRGB 转 Lab，使用 Lab 欧氏色差排序。候选范围要求两个最接近档位相邻，并满足质量/距离检查；插值使用测试液在两档 Lab 连线上的投影，投影须在端点之间。
- 当前没有完成透视校正、同图中性区域校准、任意色卡 OCR、通用液体自动定位或跨设备浓度校准。旧离线骨架中的中性区校正方案不能描述成现行页面已采用。

## 三项拒绝合同

| 判断 | 当前检查 |
| --- | --- |
| 共同取色质量 | 无效/过小选区、有效像素不足、区域颜色离散或过滤比例过高、重复色块差异过大 |
| 最近档 | 共同质量检查通过；最近色差不过大且不是同样接近的并列档 |
| 候选范围 | 共同质量检查通过；候选色差可用且最接近两档相邻 |
| 插值 | 范围可用；两档可区分，投影处于两端之间 |

当前工程阈值的真实浓度可靠性尚未校准，不能将高/中/低或通过/拒绝解释为已测准确概率。具体数值只在算法实现及参考测试维护，改阈值须记录算法版本、所有样本结果与拒绝变化。不要为使样本吻合而只放宽阈值。

主界面每项最多显示一条简短拒绝原因；范围不可用时，插值只说明依赖范围无法确定，不重复堆叠原因。取色详情可折叠，没有“取色框正确、无遮挡”勾选或下载取色记录按钮。

## 精度与记录

- 拍照插值主结果按用户要求显示整数；原始算法小数保留。确认表单可保留/编辑小数，尤其不能把 PO4 的小数原值保存成展示用的 0。
- 算法原始范围、插值、方法/版本、失败原因与最终人工结果分离；编辑人工值不覆盖原始结果。范围记录可无插值，趋势不生成虚构点。
- 当前候选范围是色卡比较范围，不是经验证的误差区间；Lab 插值也不是经过浓度校准的仪器读数。这是内部评估边界，主界面维持简洁“仅供参考”。
- 检测照片仅当次在本地临时处理，确认/取消后清理，正式记录和新备份不存检测照片。

## 素材与真实验证

原素材在 `resource/NO3`、`resource/PO4`，统一登记在 `datasets/no3` 与 `datasets/po4`。文件名标签、旧报告与用户更正都需留出处，不覆盖原图或悄悄修改标签。PO4 编号 1 的人工范围经用户纠正为 0.25–0.5，原文件名保留；用户已见过预测后修正的标签不能作为独立盲测证据。

已有多张照片不等于多份独立液体。资料缺口包括试剂批次/色卡版本、显色时间、液体真值、设备和光照。数据审计可验证路径、哈希、标注完整性和批次隔离，不凭工程测试数产生准确率。

真实评估需要：

- 每档多份独立测试液；按液体批次隔离调参与最终验证集，禁止同一液体照片泄漏到两边。
- 覆盖 Android/iPhone、常见白光/自然光、轻微角度和距离变化；标注一致的有效液体区域，并保留失败/排除原因。
- 冻结算法、模板和阈值后运行完整验证集，分别报告最近档、范围、插值的可用/拒绝与错误；包含严重跨档和全部失败案例，不只展示成功样本。
- 数值插值的浓度校准、误差指标及发布阈值须另用真实数据确认。当前不能宣称实验室级精度或确定误差。
