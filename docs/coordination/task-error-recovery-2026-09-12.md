# 任务操作错误恢复 · 2026-09-12

日志确认旧完成记录的 reopen 被 rolling schedule 拒绝（只能重开最近可修改的完成记录），原生将 StateError 返回为 operation_failed，网页因此标记存储 uncertain，后续任务被“请先重新读取本机数据”拦截。查看每日安排是只读入口，本次可正常打开。

修复：将这一明确的规则拒绝映射为 invalid_input，并显示具体原因；任务命令失败后读取权威状态并刷新页面，不重放可能已提交的操作。若读取也失败，展示重新读取入口，继续保护原存档。

验证：TypeScript、移动网页和 Android debug 构建通过；扩展并运行现有 native task commands 单项用例，覆盖拒绝重开后事务不变与后续完成/停止计划操作。模拟器同一旧记录连续拒绝后仍可打开每日安排，任务数据前后一致；没有停止用户真实计划。检查脚本的导航、日期与带图标提示定位经修正后通过。未跑整套回归，真机未测。
