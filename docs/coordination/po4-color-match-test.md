# PO4 网页比色测试（2026-09-08）

用户新增 resource/PO4 色卡和5张以“编号_人工浓度”命名的照片，要求先做与NO3类似的网页测试。已实现 [本地测试页](http://localhost:3000/po4-color-match)，检测页PO4下有独立入口。未发布、未修改App、不自动写检测记录。

## 素材及实现

- 原始6张图片复制到 public/po4（1–5.jpg及card.jpg），逐一验证SHA256与源文件一致，没有重配色或覆盖原图。artifacts/po4下的缩略图仅供人工检查，网页使用原图。
- 读取卡面档位：0、0.03、0.1、0.25、0.5、1、3 mg/L；卡面有两处0.25。正向两行四列，侧向四行两列；方向由样本几何预设或用户选择，不自动识别数字。
- 所有样本初始液体框、色卡总框为人工几何标注，位置可拖选修正。算法在模板每格中心附近自动选取较均匀区域。编号5有明显影子/遮挡，低浓度色块和杯底文字也影响取色。
- 复用NO3像素中位数、Lab色差和拒绝条件，参数化档位/行列及重复色块检查；不按人工标签调整算法或强制给值。标签只在结果之后对照。
- 页面可切换5张样本、上传其他图片、修改总框/液体/单色块框、查看候选范围和未经校准的3位小数插值、下载JSON。变更图片/方向/选区清除旧结果和确认状态。
- 数据集清单 datasets/po4/manifest.json 保留源路径、哈希、按EXIF朝向的显示尺寸、人工标签与未分配批次状态。5张图不等于5份独立液体，当前不计算准确率。
- 用户移动NO3资源目录，已修正 datasets/no3/manifest_v1.json 的旧示例路径，标签及哈希不变。

## 验证与结论

- 构建、TypeScript和相关ESLint通过；79项工程测试通过，包括新增PO4小数档位、缺档、重复0.25冲突与两种模板方向测试。
- 浏览器实际读取全部5张原始照片并导出结果；测试人工确认门槛、方向/上传后清空、375px布局和无脚本异常。自动勾选框用于覆盖交互，不代表照片遮挡已由人验收。
- NO3比色和原拍照记录流程浏览器回归通过。日志、JSON及桌面/手机截图在 web-demo/artifacts/po4/。
- 当前只是可操作的PO4网页实验，编号1更正后匹配，但其余素材显示沿用现有算法仍有明显局限，不能承诺稳定精度。后续应围绕取色区域、均匀背景、反光和低档区分验证，不按标签直接返回答案。
