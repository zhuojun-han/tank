# 当前网页版功能同步到 App

2026-09-08，用户明确要求“把 APP 同步到和网页版一样”，授权本次 WEB-005–008 及 PARITY-004 的实现与验证。本报告记录这批交付，不覆盖此前 [同步验收](app-sync-2026-09-08.md)。

## 本次范围

| 项目 | App 实现 |
| --- | --- |
| WEB-005 | 按缸/药剂保存每日平衡周期；首页及所选日显示逐日剩余天数/mL，平日虚拟已完成、末日单个补液提醒。可补选实际配液日、保留残液按原当量续配，确认后关闭旧周期及延期提醒 |
| WEB-006 | KH 所有检测入口直接输入初始/剩余 mL；使用同一张表及线性插值，结果一位小数，用户选择是否记录；保留原始滴定信息 |
| WEB-007 / PARITY-004 | PO4/KH 计划取当前缸完整有效目标的精确中值；手工输入不被持续覆盖。KH 默认 7–9，一次初始化保护旧自定义、单边和明确清空；停用指标保留目标及历史 |
| WEB-008 | 正整数天延期默认 1；未完成自动顺到今天，重复任务按实际完成日续排；支持补记/修正最新完成日和撤销。有限加药计划移动剩余日程并保留剂量/数量；按钮与日历同步 |

此前 NO3/PO4 拍照、实际旋转、独立三项判断、编辑后选择记录、五次柱状趋势/可横滑折线、范围端点与十条记录分批等功能继续保留；图像、ZIP 和长历史的资源保护没有回退。

## 数据与提醒

- Drift/JSON 升到 v11，新增 MaintenanceCycles、rollingJson、KH 原始滴定元数据及一次默认标记，目标上下限允许分别留空。旧表/字段/格式保留迁移，不把网页演示历史导入 App。
- 完整恢复先校验后事务替换；补液校验配方、体积守恒、父周期当量及同缸同药关联，拒绝循环。合并恢复仅初始化旧备份新引入的 KH 范围，不覆盖本机已清空值。
- 周期合并按父先子后重映射 ID，拒绝一父多子，并在提交事务内重核对复用父节点。任务同内容比较忽略本机通知编号，避免重复导入。版本冲突的有限加药计划拒绝合并，避免同一 planId 混入重复剂量；用户仍可经确认使用完整恢复。
- 当前未处理任务安排到期及系统每日提醒，实际完成后再排下一次；有限计划只提醒最早未处理项，补液续配取消旧提醒。归档海缸停止通知但保留业务历史。
- 通知同步队列合并为当前处理和最后一个待处理快照；慢通知服务下连续 100 次更新仅执行当前与最新两轮，避免堆积完整任务列表。趋势工具栏在 320px 窄屏的溢出已修复。
