# 网页目标范围与计划默认值联动

日期：2026-09-08。用户要求 PO4 降低、KH 提升的默认目标取当前海缸目标范围中值，并补充合理的 KH 默认上下限。本轮仅实施网页，App 差异登记 [WEB-007](app-sync-backlog.md#web-007-验收范围)。

## 交付行为

- 完整有效范围按十进制数值取中点，如 PO4 `0.03–0.10 → 0.065 mg/L`、KH `7–9 → 8 dKH`。修改范围、关闭重开或切换海缸后重新预填，表单内仍可手动修改。
- KH 首次启用使用 7–9；旧存档中已启用但上下限全空的 KH 只初始化一次，原自定义/单边范围保留，不自动启用其他缸的 KH。用户此后清空并保存，刷新不会恢复默认范围。
- 单边或非法范围不虚构中点，目标输入留空。原有 PO4 最低目标和 KH 当前缸上下限检查继续执行；KH 计划目标不套用检测结果的一位小数精度。
- 仅打开、编辑默认值或取消不创建任务或检测记录。行为与依据分别由 [产品规格](../MVP_SPEC.md)、[建议依据](../ADVICE_RULES.md)、[技术设计](../TECHNICAL_DESIGN.md) 维护。
