# NO3 / PO4 三项独立判断

2026-09-08，本地网页版；App未同步，未发布。取色方式和原有数值阈值未调整。

| 项目 | 拒绝条件 |
|---|---|
| 共用质量检查 | 液体/色卡不均或无效像素过多、重复色档不一致；失败时三项均拒绝 |
| 最近色档 | 共用质量失败、最近色差大于30、最近两档同样接近 |
| 候选范围 | 共用质量失败、最近色差大于30或第二色差大于38、两档不相邻 |
| 插值 | 候选范围检查失败、两档颜色连线长度平方不超过0.01、投影不在0至1之间 |

每项有独立status及reasons（result.judgments），JSON导出保留这些字段。状态仅为规则下“可供参考/拒绝给出”，不编造可信度百分比。最近档并列不阻止其他项目；插值失败不隐藏已通过检查的最近档和相邻候选色档范围。

与旧版本的重要语义变化：候选范围表示最相近的两个相邻色档，不保证实际浓度位于其中，不是测量误差区间。页面对该限制明确说明。插值仍未经真实浓度校准。拆分输出不代表估值准确性提高，之前NO3选区敏感问题尚未解决。

NO3确认流程允许仅带范围返回；插值为空，不生成中点，可手工填写或只保存范围。保存和取消行为维持原有流程，首页不画空插值。最近档独自通过时不据此伪造浓度记录。PO4仍为独立测试页。

- independent-judgments.mjs通过：复用旧NO3审计保存的取色数据重算，1/2/6均保留最近25档和候选范围，插值拒绝；结果保存在web-demo/artifacts/no3-audit/independent-judgments.json（未重新框选或改人工标签）。
