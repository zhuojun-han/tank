# 网页拍照确认与范围/插值记录

2026-09-07：用户授权将比色 MVP 接入网页版，并调整 NO3/PO4 记录与趋势。本轮仅修改本地网页，没有发布或修改 App。

## 最终行为

- 检测页 NO3 的照片比色入口直接打开已有 ColorMatchPanel。自动取色、手动选区修正、原质量拒绝规则、最近档及未经校准插值保留。
- 比较通过后点击“修改结果并选择是否记录”，进入当前缸的结果表单，可编辑下限、上限和插值；只有“确认并保存结果”会新增记录。“本次不记录”及分析页返回均不新增记录。
- 独立 `/color-match` 页也可进入确认流程：sessionStorage 暂存数值草稿和原当前缸ID，回主页面消费一次，校验海缸仍存在；不存照片。无已保存海缸上下文时使用主页面初始化的当前缸。
- NO3/PO4 手动录入和历史编辑均支持插值。范围要求有限非负且下限≤上限；插值可不填，填写时必须有限且在范围内，错误输入明确拒绝、不自动夹紧。
- 新记录沿用 localStorage v10，增加可选 interpolation 与 photoEstimate。photoEstimate 保存原辅助范围、插值、算法版本和素材名称，与用户确认值分开；编辑历史保留原建议。新日期使用 ISO 时间。其余任务、海缸、鱼档案及旧记录字段不迁移覆盖。
- 首页 NO3/PO4 趋势仅画插值点线；精确单值记录作为单值点。旧范围记录没有插值时不伪造中点，会提示到趋势记录补录。
- 趋势页 NO3/PO4 同时画范围竖线和插值点线，记录列表同时列出范围及插值，点击记录可编辑。其他参数维持原趋势行为；现有展示窗口（最近六条）的选择逻辑未改，首页原“近30天”未严格过滤的已知问题仍待处理。
- PO4 尚无受支持的拍照素材和算法，本轮支持其手动范围/插值记录，移除误用 NO3 示例给 PO4 固定结果的拍照路径；旧存储 photoSupported=true 也不会绕过入口判断。
