# App 同步验收 · 2026-09-08

用户本轮明确要求“同步到app里”。本轮按待同步清单的最新规则同步 Flutter，不发布网站，不引入网页演示历史，不做云端数据合并。

## 已同步

- NO3 / PO4 共用本地取色、确认流程；选择照片或调用相机；顺/逆时针 90° 从原图实际旋转像素，旋转后清空选区和结果。固定文字正向两行四列，用户框选完整色卡和测试液，自动取八块颜色，可逐块重框。不是任意色卡数字 OCR。
- 按网页算法取通道中位数、过滤截断高光/暗像素，以 Lab 色差和分段投影比较。最近档、候选范围、插值分别判断；共享质量问题拒绝全部，范围失败只给插值一条依赖原因。主结果只留“仅供参考”，没有确认取色框勾选、下载记录按钮。
- 拍照插值主结果取整数；复核默认预填三位小数，原始算法字段保留完整小数，避免 PO4 小数变成 0 后破坏范围。结果返回后正确预填范围及插值，可修改再保存，也可退出/放弃。原始范围、插值、算法版本及失败原因与确认值分开保存。临时照片确认或取消后删除，不进入正式记录和备份。
- NO3 / PO4 的跳过计时和完成后进入同一拍照流程；退出计时取消通知并清除计时状态。其他指标保留手动录入。
- 手动/拍照/编辑记录支持范围及可选插值；只接受有限非负数、上限不小于下限、插值在范围内。旧范围不补中点，单值可用于绘图。
- 首页各指标改为柱状图，每屏约五条，默认定位最新，可左右滑动全历史，只绘制插值/单值，未填插值保留空位。趋势详情显示紫色范围上下限及数字，绿色插值/单值跨过空值连接；日期按设备本地日期格式化。
- 趋势记录独立纵向滚动区最高 480px、折叠/展开、10 条一批，滚动到底追加 10 条，保留加载按钮。切换海缸/参数或折叠重置。卡片日期行不显示备注或原始 ISO；备注仍可编辑。
- PO4 / KH 重复计划确认增加“仅计算，不覆盖原计划”；不写任务或历史，原计算结果保留可查看；取消与限定范围覆盖继续保留。
- 稳定滴定体积默认 500mL 可编辑，天数=体积/每日泵出量；配方使用未取整实际天数，不再使用六天近似。显示整数天数及括号内三位有效数字。两泵的流速、单位、每日运行时间保持独立，保留容量和 KH 溶解度校验；KH 计划最低温度默认与网页一致为 20°C。
- 精简拍照、复核、记录等重复说明，保留功能开关、删除/覆盖确认、配制与复测要求；更新隐私页面中过时的 PO4 不支持说明。
