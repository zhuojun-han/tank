# 网页 KH 滴定检测

日期：2026-09-08。用户要求使用新增 `resource/KH/数值表.jpg`，KH 无计时、输入初始容积和剩余溶剂、按指定公式查表，非档点插值，一位小数，并选择是否记录。按既有网页优先流程实施；App 差异登记为 [WEB-006](app-sync-backlog.md#web-006-验收范围)，WEB-005 补液周期仍待授权。

## 交付行为

- 检测页选择 KH 后直接输入针筒读数，初始默认 1 mL，剩余读数留空；旧手动录入入口保留。
- 输入变化立即清除旧结果；切换参数或海缸不带入计算草稿。NO3 计时切 KH 时取消旧计时，新的 NO3/PO4 计时和拍照流程保留。
- 计算和取消不新增记录；确认后写当前海缸的 KH 单值。正式数值取一位小数，原始输入、未取整计算值和表格版本保存于可选 `khTitration` 字段，编辑正式结果不覆盖这些原始信息。
- 结果页、首页概览、柱状图、趋势记录和曲线点保持一位小数，包括 `8.0`、`0.0`；编辑后显示当前确认值。既有手动记录与存储键 v10 保留。

## 数值来源

唯一数据源为 [KH 合同](../../contracts/kh-titration.json)，来自用户原图的 50 档独立逐点复核，图片 SHA256 一致。公式与边界由 [技术设计](../TECHNICAL_DESIGN.md#计算与算法) 维护，不另建重复表格。测试核对非默认初始读数、原表不等间隔的 KH 差值、相邻档插值、四舍五入浮点边界和表域外拒绝。

例：初始 0.80 mL、剩余 0.29 mL → 查表读数 0.49 mL → 未取整约 7.85 dKH → 确认结果 **7.9 dKH**。原表没有 1.00 mL 档，不自行外推或补零值。
