## 实现及输入素材

- 使用 `resource/测试液与完整色卡同框示例.jpg` 与 `resource/比色卡.jpg`。已核对现有 public/no3-sample.jpg、no3-card.jpg 分别与原始资源 SHA256 完全一致，无图像编辑或重配色。
- 示例同框图 SHA256：`FD134478D1965BC97BA7EEF7E922D8B4657C584E45EB983B489A1B6905A55998`。
- 页面 `web-demo/app/color-match/page.tsx`；算法 `color-analysis.ts`；局部样式 `styles.css`。主页仅增 NO3 入口。
- 示例初始液体框及色卡总框为人工预设，不是算法自动识别瓶子/卡片。更换照片清空预设，需要重新框液体和两行四色块区域。
- 按益尔模板上行100/50/25/10、下行10/5/1/0生成8个采样框；在每格中心附近的9个候选位置中选择较均匀、非剪切像素更多的位置。可单独拖选修正每个色块；用户检查后才能比较。无任意透视校正、OCR或全图自动定位。
- 每个区域最多约数千像素采样，排除近黑及剪切高亮，以RGB各通道中位数取代表颜色，转换 sRGB/D65 Lab 计算 CIE76 色差。已有图片缓存无需传服务器；输入15MB上限，绘制取色时长边最大1600像素。
- 两处10档交叉检查后取平均；只有最近两档相邻、质量门槛通过、液体在两者Lab连线的投影位于区间内时提供候选范围。没有额外拟合浓度，也没有套用人工标签。所有质量门槛为暂定工程值，不是经过样本验证的精度阈值。
- 候选可下载JSON，包括液体及卡片选区、RGB、各档色差、拒绝理由与版本；不保存照片，不写正式海缸记录。页面刷新不恢复上传图。

## 素材实跑结果

默认示例取色与用户确认后，计算候选为 **10–25 mg/L**。10档色差约7.9，25档约8.1，5档约15.6。与已有人工10–25标签一致，但只有同一份素材，且预设选区由人工选定，不能视为独立盲测或准确率证明。手指遮挡、管壁/瓶底反光和印刷卡/透射液体的差异仍须人工检查；质量检测不保证发现所有遮挡。

## 插值参考值扩展（用户随后授权）

2026-09-07 比色 MVP 新增最近色档和插值参考值：仅通过原有质量/相邻档检查时显示；按 Lab 连线投影位置线性插值，标明未经浓度校准，保留原范围。当前示例10–25 mg/L、更接近10档、插值约17.3 mg/L；显示和JSON导出一致。构建及75项测试通过，浏览器桌面/375px操作通过。仅本地网页，App继续待同步。

算法版本 eal-no3-mvp-2。投影 t = dot(液体Lab−最近档Lab, 次近档Lab−最近档Lab) / 两档Lab距离平方；参考值 = 最近档浓度 + t × (次近档浓度−最近档浓度)。只是颜色位置到浓度的线性假设，没有真实浓度校准。仅在原拒绝条件全部通过时返回 nearestLevel 和 interpolatedValue，否则均为 null；两档等距时不声称更接近其中一档。页面保留一位小数，JSON保留计算值和方法名称。新增回归覆盖最近端点反转、端点值及拒绝时无插值；浏览器核对页面数值与JSON一致。前文不插值描述属于初版状态。
