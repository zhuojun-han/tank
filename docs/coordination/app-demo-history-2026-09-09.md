# App 日期查看用演示数据

用户要求快速删除测试指标并添加历史供查看。仅修改现有 Android 模拟器本地数据，没有改源码、安装包或网页数据。

- 删除 `AUDITFIX / AuditParameter`、其启用关联及没有填写数值/照片/备注的空草稿；其他自定义数据与海缸保留。
- 在“我的海缸”新增 NO3、PO4、KH 各 12 条，共 36 条，启用这三个指标；记录备注标为“演示数据·日期检查；非真实检测”。
- 时间覆盖 2026-08-20 至 09-08，包括跨月、同日多次、19:01、19:42、23:55、00:05；包含单值、范围加插值与仅范围，支持查看五点横滑和十条分页。
- 模拟器当前时区为 GMT，样例按该设备时区生成，未更改设备时间；更换时区后显示时间会按本地时区换算。演示记录会参与当前缸趋势及建议，不能当真实检测使用。
- 写入前备份、原检测记录与任务逐行保留校验、SQLite 完整性/外键检查及设备写回逐字节校验通过。备份、生成脚本、记录 ID 清单及截图在本地忽略目录 `artifacts/history-review-2026-09-09/`，生成脚本为 `artifacts/seed-history-review.py`。按该清单可精确清理本批 36 条，不按日期批量删除其他记录。
