# 海盐配制计算器

## 用途与输入

该工具已进入 `web-demo/` 与 Flutter App，用于估算在一桶起始水中加入多少海盐，包含以下输入：

- 初始比重（SG）：默认 `0`。界面中的 `0` 是“RO/DI 无盐水”的快捷写法，计算时按淡水起点 `SG 1.000` 处理；也可填写 `1.000–1.040` 的已有水体比重。
- 目标比重（SG）：默认 `1.025`，必须高于初始比重。
- 起始水量：默认 `20 L`，指加入海盐前量取的水量，不声称等于混合后的精确最终体积。
- 包装基准：每升水配到包装指定比重所需的海盐质量。默认展示 Red Sea Salt 的 `38.2 g/L`、`SG 1.0255` 示例值，用户必须按实际品牌包装同时修改克数和对应比重。

`1.025` 是比重，不是 `1.025 g/L` 的盐质量浓度。不同海盐产品为达到相同比重给出的干盐质量不同，因此实现不使用一个不可修改的跨品牌常量。

## 估算公式

当初始值为 `0` 时，先替换为 `1.000`。随后按比重差作线性配盐估算：

```text
估算海盐质量（g）
= 起始水量（L）
× 包装标注的 g/L
× (目标 SG - 初始 SG) / (包装基准 SG - 1.000)
```

例如，`20 L` RO/DI 水、包装基准 `38.2 g/L @ SG 1.0255`、目标 `SG 1.025`，线性估算约为 `749.02 g`。界面建议先加入估算量的 `90%`，充分溶解、循环、达到产品标注的参考温度并复测后，再少量使用预留部分微调。`90%` 是防止一次过量的操作缓冲，不是化学精度声明。

## 使用边界

- 比重受温度和量具校准影响；最终值必须以校准后的盐度计、折射仪或产品指定量具的实测结果为准。
- 比重差与干盐质量的线性关系只用于起始估算，不宣称覆盖所有配方、温度和浓度范围。
- 工具目前只计算“加盐提高比重”；目标不高于初始值时拒绝计算。降低比重需要独立的换水/稀释模型。
- 应先量水，再把盐逐步加入水中并循环；不要把水直接倒在干盐上，也不要在有鱼或珊瑚的展示缸中直接混合海盐。
- 网页和 App 均只提供起始估算，不替代海盐产品包装说明或充分溶解后的实测调整。

- [Instant Ocean Sea Salt FAQ](https://www.instantocean.com/en/instant-answers/faqs/sea-salt)：说明应把盐加入水中、循环/充气后再测量，并避免在有生物的缸内直接混盐。
