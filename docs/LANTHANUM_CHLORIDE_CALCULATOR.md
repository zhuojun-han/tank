# 氯化镧降低 PO4 理论计算器

## 定位与边界

本功能已同时进入网页版 Demo 与 Flutter App。两端都固定按纯度 `99.9%` 的七水合氯化镧 `LaCl3·7H2O` 配制指定强度母液；两端均允许选择母液最终体积，默认 `500 mL`。改变总体积只按比例改变称取质量，不改变每毫升强度。计算器再根据当前/目标 PO4、实际净水体积和单日计划降幅计算每日理论取液量，新版在配好确认后保存为有限配液周期，旧 Flutter 保留分日一次性条件任务。它不自动投药、不测量实际反应效率，也不能把计算结果称为适用于海缸的“安全剂量”或替代产品标签、试剂 SDS、专业判断和对生物的持续观察。

目前没有证据支持一个同时适用于纯氯化镧、所有商品配方和所有海水缸的通用安全 PO4 日降幅。不同海缸的磷形态、有机物、盐度、碳酸盐体系、生物负荷和颗粒捕获能力都会影响结果。因此：

- “每日最大计划降幅”限制在用户指定的 `0.1–0.5 mg/L` 范围内，但该范围不是系统推荐或验证的通用安全值。
- 若用户使用的是没有海水缸投加说明的实验室纯氯化镧，普通化学品标签或 SDS 不能自动变成水族用量依据；计算器显示结果也不代表该日降幅已被证明安全。
- 厂家对其专有液体产品给出的浓度、最大用量或操作说明，只适用于该具体产品，不能反推纯 `LaCl3` 或 `LaCl3·7H2O` 的通用安全用量。
- 计算器只给出不含效率补偿的理论化学计量量。实际下降不足时不得按“估计效率”自动加量，应复测并重新评估。

## 必填输入

网页版目标预填与刷新遵循 [产品联动规则](MVP_SPEC.md#计算与通知)。

1. 当前 PO4：采用最近一次人工确认的单值，单位必须是以 `PO4` 计的 `mg/L`，不能把以元素磷 `P` 计的结果直接代入。
2. 精确目标 PO4：不得低于 `0.03 mg/L`，且必须小于当前值；当前值已经达到或低于目标时不建议投加，也不生成任务。
3. 海缸实际净水体积：单位 `L`，界面默认 `200 L`；实际使用时应扣除造景、底砂和设备占用，不能仅使用鱼缸标称容积。
4. 每日最大计划 PO4 降幅：由用户在 `0.1–0.5 mg/L/day` 内输入，默认 `0.1 mg/L/day`；不得称其为系统保证的安全值。

计算器固定采用七水合氯化镧 `LaCl3·7H2O` 和 `99.9%` 纯度，不再显示盐形态或纯度输入框。检测方法可靠下限、日降幅依据和安全复选框也已移除。用户实物若不是该形态和纯度，当前计算器不适用。

范围型、未确认或时间过久的 PO4 记录不能直接驱动投加计划，应先复测并保存新的人工确认单值。记录是否“时间过久”的阈值仍待依据实际检测方法和产品资料确认，Demo 不擅自设定。

## 理论计算

简化的理论反应为：

```text
La3+ + PO4^3- -> LaPO4(s)
```

镧离子与磷酸根按 `1:1` 摩尔比形成磷酸镧沉淀。计算采用以下摩尔质量：

- `PO4`：`94.971 g/mol`。
- `LaCl3·7H2O`：`371.37 g/mol`。

设：

- `Ccurrent` 为当前 PO4，`Ctarget` 为目标 PO4，单位均为 `mg/L`；
- `V` 为实际净水体积，单位 `L`；
- 七水合氯化镧的摩尔质量固定为 `371.37 g/mol`；
- 试剂纯度固定按 `P = 0.999` 计算。

则：

```text
deltaPO4_mg_per_L = Ccurrent - Ctarget
totalPO4_mg = deltaPO4_mg_per_L * V
salt_g = totalPO4_mg * (371.37 / 94.971) / 1000 / 0.999
```

等价质量因子为：

- `LaCl3·7H2O`：每理论去除 `1 mg PO4` 需要 `3.9104 mg` 纯盐；
- 按固定纯度 `99.9%` 修正后，页面称量值约为 `3.9143 mg` 七水合氯化镧试剂。

这些数值只是由分子式和摩尔质量得到的化学计量结果，不含海水中碳酸盐、有机物、其他磷形态、混合、沉淀捕获或测试误差造成的效率变化。Demo 不提供“反应效率百分比”输入，也不通过乘系数补偿可能的损失。

## 可选体积的固定强度母液与每日稀释液

用户指定母液强度为“每 `1 mL` 母液使 `100 L` 水体理论降低 `0.1 mg/L PO4`”。这等价于每毫升母液理论处理 `10 mg PO4`。按 `1:1` 摩尔关系、七水合物摩尔质量和 `99.9%` 纯度计算：

```text
stock_reagent_mg_per_mL = 10 * (371.37 / 94.971) / 0.999
                             = 39.142658 mg/mL
stock_batch_g = 39.142658 * 500 / 1000
              = 19.571329 g
```

1. 设所选母液最终体积为 `Vstock mL`，称取质量为：

   `19.571329 × Vstock ÷ 500 g`

   默认 `500 mL` 时仍为约 `19.571329 g`。先用适合该试剂且符合产品说明的水溶解，再定容至所选最终体积；这里的体积是最终总体积，不是在同体积水中再加入药品。改变总体积不会改变每 `1 mL` 母液理论处理 `10 mg PO4` 的强度。
2. 设用户确认的每日最大计划 PO4 降幅为 `Dmax`，计划天数为：

   ```text
   days = ceil((Ccurrent - Ctarget) / Dmax)
   ```

3. 第 `i` 日的计划降幅 `Di` 不超过 `Dmax`；前几日取 `Dmax`，最后一日只取剩余差值。对应的母液体积为：

   ```text
   Di = min(Dmax, 当日开始前剩余的 PO4 差值)
   stock_mL_i = Di * V / 10
   ```

   因此在默认 `200 L` 水体中，理论降低 `0.1 mg/L` 取 `2 mL` 母液，降低 `0.5 mg/L` 取 `10 mL`；当总差值不能被 `Dmax` 整除时，最后一日取用的母液会更少。母液是固定强度的储备液，全程用量不必等于 `500 mL`。

4. 当日先量取上述母液，再用合适的水定容至最终 `500 mL`。界面可以显示名义上的补水差值：

   ```text
   nominal_dilution_water_mL_i = 500 - stock_mL_i
   ```

   实际配制应逐步加水至最终体积刻度，不能另量取该名义差值后假设混合体积必然严格相加。

每一日显示的理论降幅只用于安排复测，不能当成实际下降保证。母液的容器材质、保存期限和稳定性必须遵循所用试剂/产品资料；目前没有适用于所有试剂形态的项目内验证，不能由 Demo 编造。

## 每日待办与停止条件

新版网页/WebView App 新建计划使用 [共用配液周期](MAINTENANCE_DOSING_CALCULATOR.md#理论调整计划复用新版网页与-webview-app)，不再固定每天稀释为 500 mL；按泵流速、运行时间与瓶体积确定浓度。下述逐日条件任务和固定工作液示例仅保留为旧存档与旧 Flutter 的兼容行为。

确认计算结果后，Demo 或 App 会严格按计算出的预计天数创建有限数量的分日任务，从当天起连续写入任务月历，直到理论计划达到目标值；它不是普通的永久重复任务。每一项必须保留相同计划 ID、当天序号、真实本地日期、理论母液体积和以下步骤；这些是条件提醒，不得解释成连续投加授权，也不得生成“直接一次性加入”的任务。网页版提供稍后、停止后续计划及当日完成操作；停止任一日会把所选当天保留为停止记录，并将同一计划的后续未完成事项从月历隐藏，历史数据仍保留：

1. 投加前重新检测 PO4，并同时检查 KH、浑浊度和缸内鱼、珊瑚及无脊椎动物状态。
2. 若 PO4 已达到或低于目标，或已经达到 `0.03 mg/L`，停止剩余计划并重新评估；不得为了用完母液继续投加。
3. 若 PO4 结果异常、KH 明显变化、出现持续浑浊或生物应激，立即停止，不执行当天投加，并寻求有资质的水族/水化学专业意见。
4. 仅在机械过滤或蛋分正常工作、沉淀能够被捕获时，按当天经复核的体积缓慢加入过滤入口附近；不得直接快速倒入展示缸或对着生物投加。
5. 按实际产品说明及时更换或清洁滤材，避免沉淀继续留在系统内。

计算器只创建带日期的待办，不控制泵、加药机或其他硬件。后续某天是否执行必须以当天复测和观察为准；完成任务不代表系统证明该剂量安全或达到目标。月历显示任务安排，不代表系统通知已经由网页版触发。

## 化学品操作安全

- 读取实际化学品标签和 SDS；确认化学式、水合形态、纯度及适用范围。
- 称量、配制和处理溅洒时佩戴耐化学品手套与护目镜，避免吸入粉尘、接触皮肤和眼睛。
- 在通风、远离儿童和宠物的区域配制，使用清晰标注且不可误作饮用容器的专用器具。
- 不与其他药剂在同一容器中混合；若产品说明、SDS 与本页面冲突，以更严格的要求为准。
- 发生人员暴露时按 SDS 处置并联系当地中毒控制/医疗机构；本 Demo 不提供医疗急救判断。

## 依据与证据边界

研究与公共化学资料：

- [美国 EPA 的镧盐除磷报告](https://nepis.epa.gov/Exe/ZyPURL.cgi?Dockey=9101YSAA.TXT)记录了镧与正磷酸盐近似 `1:1` 摩尔反应及磷酸镧沉淀；该资料用于化学计量依据，不等于海水缸安全投加试验。
- [PubChem：Phosphate Ion](https://pubchem.ncbi.nlm.nih.gov/compound/Phosphate-Ion)、[Lanthanum trichloride](https://pubchem.ncbi.nlm.nih.gov/compound/64735)和[Lanthanum chloride heptahydrate](https://pubchem.ncbi.nlm.nih.gov/compound/165791)用于核对分子式、摩尔质量和化学品危害信息。
- [2020 年镧基除磷材料综述](https://pubmed.ncbi.nlm.nih.gov/32949878/)说明镧材料的除磷行为会受溶液化学、有机物等条件影响，并讨论潜在环境影响；它支持“不自动用固定效率补偿”，不提供海水缸通用日降幅。

厂家标签示例：

- [Brightwell Aquatics Phosphat-E 官方说明](https://brightwellaquatics.com/products/phosphat-et.php)要求在机械过滤或蛋分入口附近使用并去除形成的颗粒，也提示过快降低可能刺激敏感珊瑚。该网页描述的是厂家的专有液体产品，只用于证明“颗粒捕获、缓慢处理和观察生物”的工作流需要，不能把其每毫升能力或最大产品用量套用于纯氯化镧。

以上资料不能证明本 Demo 的计划对任一具体海缸安全。真实适用性仍需要实际产品资料、可靠检测、受控的小步调整和独立验证。
