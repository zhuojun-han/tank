| 项目 | 同步前 Flutter 状态 | 处理范围 |
| --- | --- | --- |
| 鱼缸、9 种立绘、游动 | 已同步 | 保留现有实现 |
| 海盐计算器 | 已有同样默认值及包装基准 | 回归验证 |
| 提醒总开关 | 已有持久化、取消和重排 | 保留系统通知机制 |

| 周期任务 | 按实际完成时间推进到期日 | 增加开始日固定周期、可见日期展开、逐日完成/恢复、过去日期默认完成 |

| 稍后 | 已有精确 snooze 事件与通知 | 同步当天日历入口与发生日隔离 |
| 备份 | App JSON/ZIP v8，网页是浏览器状态 | 保留旧 App 导入，新字段 round-trip；不把网页 localStorage 冒充 App 备份 |

两端计算器都是理论条件计划，不控制泵硬件。本表所列功能已完成本轮同步；鱼缸、海盐和提醒开关复用原有实现。

## 验收结果与保留边界

- Flutter 分析 0 问题，169 项全量测试通过，Android debug APK 构建成功。详细日志、大小与哈希见 [当前状态](CURRENT_STATUS.md)。
- 旧周期任务保留原推进方式；用户编辑时才以明确选择的开始日期转为新规则，原事件历史保留。新规则允许过去日期，采用默认完成边界和逐日例外，不预生成无限历史或未来任务。
- 新日期周期系统通知预排近两次实际发生日，打开、恢复 App 或处理任务时补排；尚无长期不打开 App 的无限后台补排。旧周期和单次计划继续使用原系统提醒机制，关闭总开关不删除任务。
- App JSON/ZIP 升为 v9，兼容旧 v1–v8。网页源码没有 App 备份入口，因此没有新增把浏览器 localStorage 直接当作 App 快照导入的功能。
- 新版 APK 未安装到模拟器或真机，本轮不宣称完成通知栏、后台策略、相机、真实投加效果或 iOS 验收。
