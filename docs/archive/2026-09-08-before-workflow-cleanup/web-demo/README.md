# 澜礁海缸水质助手 Web Demo

2026-09-08：新增 PO4 / KH 每日平衡补液周期。设置中的稳定滴定配方可确认添加；平日自动列入所选日期的已完成，最后一天及逾期提醒补液；支持按实际残液及已有药量续配。仅本地网页已实现，App 待用户确认后授权同步。详见 [工作记录](../../../coordination/maintenance-cycle-web-2026-09-08.md)。

首页只展示本日未完成事项；首页和任务页“待处理”将同一 KH/PO4 加药计划合并为一项，计数按合并项计算。“计划与所选日记录”中的加药总计划只保留“查看每日安排”和“停止后续计划”，前者用页内详情完整列出该计划的全部日期、状态和说明；当天操作留在日历详情。日历任务卡将长说明折叠，完成按钮独占主操作行，稍后与停止/跳过并排，已完成状态和恢复按钮合为紧凑行。用户添加的“每 N 天”周期规则可选择过去、今天或未来的开始日期；若从过去开始，今天之前符合间隔的执行日默认为已完成，并可逐日重新标记为未完成。周期任务卡右上角的“•••”可重新编辑名称、开始日期、提醒时间和重复间隔，保存时更新原规则并保留已有逐日完成/跳过记录。周期规则不进入“待处理”，只在“全部”展示，但实际发生日仍进入首页和日历待办。“稍后 1 小时”保存准确到期时间，只处理当天；到期后自动恢复待办，开启网页提醒且页面打开时会再次弹窗，重新打开网页也会处理已到期任务。跳过或停止后的事项不再出现在日历日期格和“当天待办”，后续日期也会隐藏，但处理记录仍保留在浏览器数据中。任务页“已完成”只展示本日已完成事项，并可将其中任一事项重新标记为未完成；“全部”只展示仍在运行的周期任务规则和仍有未完成天数的 KH/PO4 加药总计划，已停止周期不显示。

两种加药计划重新计算通过后，若当前海缸在新计划开始日及以后已有同类计划，会用网页内对话框询问是否覆盖，不再调用浏览器原生确认框。可选择“仅计算，不覆盖原计划”，查看本次母液配方、用量、天数及全部每日安排；结果明确标注未加入日历，原任务及完成/跳过历史保持不变，不创建重复任务。选择覆盖才删除并替换新计划开始日及以后的同类旧任务；更早日期的旧计划、完成状态和历史记录保留。取消则保留原计划及输入。加载已有浏览器数据时也只清理被更新计划日期范围覆盖的旧任务；其他海缸、另一种药剂和普通周期任务不变。“仅计算”选项已在此前 App 同步批次完成；本次新增补液周期仍单独待同步。

这是正式 Flutter App 开发前的响应式交互原型，用于验证首页养鱼模拟器、检测、趋势、维护任务、设置和多海缸管理流程。

Demo 使用浏览器 `localStorage` 保存演示数据。页面中的通知、拍照辅助估值和移动端后台计时均为交互模拟，不代表系统通知、正式图像算法或 Flutter 平台能力已经实现。

## 已覆盖的原型流程

- 当前海缸切换和新增海缸。
- 首页最上方的养鱼模拟器：点击鱼缸可按当前海缸新增、编辑或删除鱼种档案，保存品种、数量、入缸日期和立绘。内置目录提供小丑鱼、双斑宝石海金鱼公/母、蓝眼海金鱼公、深水樱花宝石、火焰仙、紫吊、粉蓝吊和东非金剪刀共 9 个带独立透明立绘的选项；用户也可新建其他鱼种并上传 PNG、JPG 或 WebP 立绘。鱼缸使用用户选定的自然珊瑚礁背景，不再叠加旧版 CSS 假石和沙底。实际数量完整保存，画面最多渲染 24 条鱼以控制性能。鱼使用逐帧二维运动，除鱼身和约 4 px 安全边距外可到达几乎整个可见水域；靠近四壁时先减速再转向，触壁只作兜底反射。每条鱼也会间隔约 8–16 秒在开阔水域随机换向，鱼头根据实际水平速度朝向，不会倒着游或频繁来回抽动。
- 首页仅本日未完成事项、KH/PO4 计划合并展示及各参数近 30 天趋势摘要。
- 首页设备当天日期，以及依据最近记录和用户目标范围生成的 NO3/PO4 维护建议。
- NO3、PO4 拍照辅助估值演示及所有参数的手动录入。
- 按海缸和参数保存检测计时默认值。
- 历史记录编辑、目标范围和趋势展示。
- 维护任务新增、完成、跳过和稍后提醒；月历按真实年月翻页，每个日期格直接显示当天事项，选中日期后每一项都有独立的“完成本次”和“跳过本次”文字按钮。普通周期任务只保存一条规则，当前六周视图按间隔动态展开，不会预生成无限任务；单次处理不会删除后续周期。
- 任务页和设置页提供“网页内到期弹窗提醒”开关，默认关闭；开启后网站保持打开时，同一天自动弹出一次当前海缸的当天待办。开关和当日关闭状态保存在浏览器本地，但不宣称网页关闭后仍能发送手机系统通知。
- KH、Ca、Mg、K 的按缸启用以及自定义水质参数。
- 氯化镧降低 PO4 的理论化学计量、可选体积固定强度母液、分日 500 mL 稀释液和每日复测待办。
- 碳酸氢钠提升 KH 的每日消耗补偿、可选体积/整数毫升强度母液、0–40°C 溶解度筛查、有限分日计划和每日复测 KH/pH 待办。
- 海盐配制计算器：初始比重默认 `0`（RO/DI 无盐水快捷值）、目标比重默认 `1.025`，结合起始水量和可编辑的产品包装 `g/L` 及对应比重估算所需海盐质量。

## 碳酸氢钠 KH 计划边界

- 仅适用于未烘焙的 `NaHCO3`，不适用于碳酸钠、复合缓冲剂或品牌浓缩液。
- `100 L` 提升 `1 dKH` 理论需要约 `3.00025 g` 纯 `NaHCO3`，实际称量再按用户填写的包装纯度折算。
- 默认净水量 `200 L`，每日 KH 消耗默认 `0.5 dKH`，计划单日净升幅默认 `0.5 dKH`、允许 `0.1–1.0 dKH/日`；每日投加当量明确拆成净提升和消耗补偿。
- 母液最终体积默认 `500 mL` 且可修改；强度可选每 `100 L` 提升 `0.1 dKH` 所需 `4/6/8/10 mL`，默认 6 mL 档约为 `50.004 g/L` 纯品。
- 用户输入 `0–40°C` 的母液最低温度；程序插值公开溶解度数据并仅使用保守换算上限的 80%，低温下过浓档位会被拒绝。这是筛查边界，不是精确饱和模型。
- 计算后只创建预计天数内的有限条件任务。每一天都必须先复测 KH/pH；达到目标、重算无需添加或出现异常时停止当天及后续计划。
- 完整公式、来源和操作边界见 [`../docs/SODIUM_BICARBONATE_KH_CALCULATOR.md`](../../../SODIUM_BICARBONATE_KH_CALCULATOR.md)。

## 海盐配制计算器边界

- `1.025` 指比重 SG，不是盐的质量浓度；初始输入 `0` 在计算时按无盐水 `SG 1.000` 处理。
- 默认包装基准 `38.2 g/L` 是 Red Sea Salt 在约 `SG 1.0255` 条件下的示例值，不是所有品牌通用常量，用户应按自己的海盐包装修改。
- 结果按比重差作比例估算，并将 90% 显示为建议首次加入量；充分溶解、循环并达到产品参考温度后必须使用校准量具复测和微调。
- 当前仅支持通过加盐提高比重，不计算降盐度所需的稀释换水量，也不应在有生物的展示缸中直接混盐。

完整公式和来源见 [`../docs/SALINITY_CALCULATOR.md`](../../../SALINITY_CALCULATOR.md)。

## 氯化镧计算器安全边界

- 计算器只处理以 `PO4` 计的 `mg/L` 单值；盐固定为纯度 `99.9%` 的七水合氯化镧 `LaCl3·7H2O`。实际净水体积默认 `200 L`，精确目标不得低于 `0.03 mg/L`，计划单日最大降幅限制为 `0.1–0.5 mg/L`。
- 理论质量只采用 `La3+ + PO4^3- -> LaPO4` 的 `1:1` 摩尔关系和七水合物 `371.37 g/mol` 的摩尔质量，不提供反应效率补偿。
- 母液最终体积可选；默认 `500 mL` 时称取 `19.571329 g`，其他体积按 `19.571329 × 体积 ÷ 500` 缩放。每 `1 mL` 母液仍理论处理 `10 mg PO4`，即让 `100 L` 水体降低 `0.1 mg/L`。每日取液量按 `计划降幅 × 实际净水体积 ÷ 10` 计算，再定容至最终 `500 mL` 工作液。
- 目前没有适用于纯氯化镧和所有海水缸的通用安全 PO4 日降幅。`0.1–0.5 mg/L` 是用户指定并要求实现的可选计划范围，不应显示成系统验证的安全范围。
- 简化表单不再要求检测可靠下限、日降幅依据或安全复选框，但仍明确提示使用机械过滤/蛋分捕获沉淀、每日复测并在异常时停止。
- 确认计划后，计算器会把全部分日事项从当天起按连续真实日期加入任务月历；这些是条件提醒而非连续投加授权。每一天仍要求先复测 PO4/KH 并观察生物；达到目标、读数异常、持续浑浊或生物应激时，停止当天会同时停止该计划的后续事项。计算器不自动投药、不控制硬件，也不能替代产品标签、SDS 或专业判断。
- 配制时应按实际标签/SDS 佩戴耐化学品手套和护目镜，避免粉尘、皮肤/眼睛接触，并使用清晰标注的专用器具。

完整公式、依据和证据边界见 [`../docs/LANTHANUM_CHLORIDE_CALCULATOR.md`](../../../LANTHANUM_CHLORIDE_CALCULATOR.md)。

## 技术边界

- 当前持久化仅使用浏览器本地存储，不使用 SQLite/Drift。
- 鱼类档案当前只保存在浏览器本地 `reef-demo-state-v10`；v9 及更早的鱼类档案会保留品种、数量和日期并补上小丑鱼内置立绘。自定义立绘原图限制为 8 MB，只接受 PNG/JPG/WebP，在浏览器内转为不超过约 450,000 字符的数据 URL 后随当前海缸本地保存，不会上传云端；浏览器存储空间不足时会明确提示。Flutter App 已同步鱼类档案、自定义立绘和全部 9 种内置鱼种。
- 当前不触发 Android/iOS 系统通知。
- 示例照片只用于演示人工确认流程，不执行正式颜色估值。
- 当前网页原型不是首版正式产品；正式客户端仍计划使用 Flutter 实现。
- 氯化镧计划只是理论计算与待办原型，不代表真实海缸已验证、Flutter App 已实现或任何剂量已被证明安全。
- 碳酸氢钠 KH 计划当前只接入网页版；结果是理论当量和条件待办，不代表真实海缸已验证或已同步 Flutter App。
