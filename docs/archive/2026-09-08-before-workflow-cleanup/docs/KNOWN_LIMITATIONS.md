# 已知限制

## 拍照辅助估算

- 当前只有一张带 10–25 mg/L 人工标签的益尔 NO3 同框示例，没有足够独立样本计算准确率、确定误差或置信度阈值。
- 当前实验性算法源码只处理调用方预提取的颜色和质量指标；色卡/试管自动定位、完整图片质量指标计算和真实设备颜色稳定性尚未验证。
- 光照、白平衡、反光、试管液量、显色时间、试剂批次和色卡老化都可能影响人工比色和辅助估算。
- PO4 的品牌、色卡、单位、量程、显色时间和样本尚未提供，不能实现或启用 PO4 拍照估值。
- 用户应始终核对并确认最终结果；无法估值时应重拍或手动录入。

## 通知与后台行为

- 通知权限被拒绝、系统通知关闭、设备关机、省电策略或平台调度限制都可能导致提醒延迟或缺失。
- Android 精确闹钟属于可选特殊权限；未授权时计时通知降级为非精确调度。维护任务默认使用非精确调度。
- App 内任务状态以本地数据库为准，通知展示不会自动完成任务。
- 不同 Android 厂商的后台限制以及 iOS 调度时效必须在真实设备上验证。

## 平台与发布

- Android API 36 模拟器可以验证基础流程，但不能替代 Android 真机相机、通知、省电和文件存储回归。
- Windows 无法构建或运行 iOS；iOS 构建、签名、通知、相机和真机回归仍需 macOS、当前 Xcode 和 iPhone。
- 正式应用 ID、发布签名、商店账号、图标和隐私政策公开地址尚待发布前确认。
- Release 包的 16 KB 内存页兼容性、商店签名和最终安装包尚待发布配置完成后验证。

## 数据与恢复

- 首版没有账号或云同步，设备遗失且没有可用备份时无法恢复数据。
- 本地空间不足可能导致临时照片处理或数据备份写入失败；已确认数值应优先保留。
- 完整备份是用户主动导出/导入的数据快照，不是账号或自动云同步；导入会经二次确认后以备份为准替换本机业务数据，且不迁移照片、通知权限或其他操作系统设置。
- 跨时区后界面按设备当前时区显示 UTC 时间点，重复任务的本地提醒需要在时区变化后重新核对。
