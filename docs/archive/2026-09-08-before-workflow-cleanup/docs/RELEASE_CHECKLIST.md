# 发布检查清单

本文只记录实际发布前必须完成的验证，不表示当前已通过。

## 产品与账号

- [ ] 确定正式应用名称、Android applicationId、iOS Bundle ID 和版本号。
- [ ] 准备最终图标、截图、商店文案、支持联系方式和公开隐私政策 URL。
- [ ] 配置 Android release 签名；不得使用 debug key 发布。
- [ ] 配置 Apple Developer 账号、证书、描述文件与 App Store Connect。

## 自动化质量

- [ ] `dart format --output=none --set-exit-if-changed lib test integration_test` 通过。
- [ ] `flutter analyze` 通过。
- [ ] `flutter test` 全部通过。
- [ ] Android release APK/AAB 构建成功并记录哈希、大小和工具版本。
- [ ] 检查 APK/AAB 内原生库的 16 KB 内存页兼容性。

## Android 真机

- [ ] 至少一台 API 24–32 与一台 API 33+ 真机完成安装/升级/冷启动。
- [ ] 验证相机授权、拒绝、永久拒绝、返回设置、拍摄方向、对焦、反光和照片删除。
- [ ] 验证通知授权、拒绝、精确闹钟拒绝降级、点击路由、重启后恢复和省电模式。
- [ ] 验证进程终止后计时草稿与绝对结束时间恢复。
- [ ] 验证无网络、低存储空间、备份导出/恢复、时区切换和大字体。

## iOS 真机

- [ ] 在 macOS 与当前 Xcode 完成 Debug/Release 构建。
- [ ] 在至少一台 iPhone 验证相机、权限拒绝、照片方向和缓存临时文件清理。
- [ ] 验证通知授权、前台展示、后台/终止点击路由和系统调度限制。
- [ ] 验证文件分享/恢复、时区切换、深色模式、VoiceOver 和大字体。

## 数据与安全边界

- [ ] 从 schema v1、v2、v3 的真实副本升级至当前版本并确认数据保留。
- [ ] 验证完整数据备份、不含照片、旧含照片备份兼容、无效关联、损坏文件、空间不足和安全解压限制。
- [ ] 确认所有时间点以 UTC 保存、按设备时区显示。
- [ ] 确认建议只读取用户确认值、用户目标和已保存历史，并展示来源与安全边界。
- [ ] 确认拍照页面、隐私页和商店文案均未宣称未经验证的精度。
- [ ] PO4 资料不足时，确认产品内没有 PO4 拍照估值入口或暗示。

## 算法发布门槛

- [ ] 按独立测试液批次隔离调参与最终验证集。
- [ ] 冻结算法版本、色卡版本和阈值后运行完整验证集。
- [ ] 报告可估值率、单档正确率、相邻范围覆盖率、严重跨档错误率和拒绝率，包含全部失败案例。
- [ ] 只有真实证据达到另行确认的发布门槛后，才改变“实验性辅助估算”状态。
