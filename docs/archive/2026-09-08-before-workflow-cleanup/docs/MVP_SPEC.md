# MVP 页面与交互规格

本文记录已经确认的首版页面结构和交互方向。所有功能仍处于规划中，尚未实现。

## 全局导航

底部导航固定为四个入口：

1. 首页
2. 检测
3. 趋势
4. 任务

海缸管理和其他配置从页面右上角的设置入口进入，不占用底部导航位置。当前海缸应在首页清晰显示，并允许切换。

## 首页

- 网页版首页最上方显示当前海缸的养鱼模拟器；点击鱼缸可管理该海缸的鱼种、数量和入缸日期。
- MVP 内置鱼种目录先只提供小丑鱼，并在选择卡和鱼缸中显示其立绘。用户可新增其他鱼种、填写名称并上传 PNG/JPG/WebP 立绘；自定义图片应在浏览器内限制格式、尺寸和持久化大小，不上传云端。库存数量必须完整保存，游动画面可设置有限渲染上限并明确提示，不因性能上限截断档案数量。
- 鱼的完整可见尺寸不得越过水域四壁；临近边界时应平滑减速和转向，鱼头必须随实际水平速度翻转，并加入幅度受限的上下巡游，避免倒着游、瞬间硬折返或只有水平直线运动。
- 显示当前海缸。
- 显示最近一次 NO3、PO4 记录。
- 在水质趋势之前显示当前海缸的所有未完成维护事项；任务标记完成后立即从首页移除。
- 为当前海缸的每个已启用参数分别显示一张近 30 天趋势摘要图，无历史数据时显示真实空状态。
- 提供切换海缸和添加海缸的入口。

## 检测

- 内置 NO3、PO4、KH、Ca、Mg、K；KH、Ca、Mg、K由用户针对每个海缸自行选择是否启用。
- 用户可新增自定义参数并填写简称、名称和单位；自定义参数默认只支持手动录入。
- 启用或新增参数后，自动进入当前海缸的首页、检测、目标范围、历史编辑和趋势模块；停用只隐藏关注入口，不删除历史记录。
- 每个海缸至少保留一个启用参数，各海缸的启用列表互不影响。
- 选择当前海缸及其已启用检测项目。
- 显示所选试剂的操作提示，并由用户在加完试剂后启动短时显色计时器。
- 益尔 NO3 初始显色时间为 5 分钟；提供 3/5/10 分钟快捷项，并允许用户按分钟和秒自定义默认计时（10 秒至 60 分钟）。
- 默认计时时长按 `海缸 + 参数` 独立保存；修改后该海缸该参数之后每次检测都继续使用，直到用户再次修改。
- 计时开始后锁定当前时长；暂停可以继续，若要改时长需先重置。保存或放弃检测不清除已保存的默认时长。
- 计时器以结束时间戳持久化，切到后台或重启 App 后按实际剩余时间恢复。
- 计时结束时使用声音、振动和系统本地通知；点击通知返回本次检测。
- 允许跳过计时直接拍照，但需要明确提示应遵守试剂显色时间。
- 拍摄测试液与完整色卡。
- 拍照前显示摆放示意与取景辅助框；相机权限不可用时仍可手动录入结果。
- 照片不合格时显示具体原因并允许重拍或改为手动录入。
- 显示辅助估算档位或相邻范围、置信度及必要的失败原因，不输出未经验证的伪精确小数。
- 允许用户确认、改选色卡档位/相邻范围、重新拍摄或放弃本次结果。
- 将用户确认后的结果保存到当前海缸。
- 检测照片只在应用缓存中临时压缩并服务于当次人工比色；确认、取消或改为手动录入后删除，不写入正式记录或新备份。长期保存数值、拍摄时间和必要的质量/复核元数据。

检测计时器仅服务于当前检测流程，不属于周期性维护任务。

## 趋势

- 按当前海缸展示 NO3/PO4 历史曲线。
- 在图表中显示用户设置的目标范围。
- 查看单条记录的时间、估算结果和最终确认结果。
- 范围型结果以中点作为折线位置，并显示上下界；不能把中点描述成真实测量值。
- 点击历史记录进入详情并提供“编辑记录”。用户可修改所属海缸、检测项目、检测时间、最终单档/范围、备注和试剂配置。
- 算法原始估值、置信度和原始拍摄时间不可被手动编辑覆盖；修改后的记录显示“已手动修改”和最后修改时间。
- 保存修改后立即重算对应海缸/指标的首页摘要、趋势和建议；若更换所属海缸或指标，原位置和新位置都要刷新。
- 数值必须是非负数；范围下限不得大于上限；单位统一显示为 mg/L。
- 删除记录前二次确认；旧版本已经留档的照片仍可单独删除并保留数值记录。
- 数据不足两条时只显示记录点，不声称上升或下降趋势。

## 任务

- 按海缸展示待办、逾期和已完成维护任务。
- 支持新增、编辑、停用和完成任务。
- 支持用户自定义重复间隔和提醒时间。
- 网页 Demo 的月历仅动态计算当前可见六周内的重复发生日期，不提前生成无限任务；用户从某个日期完成或跳过时只记录该次发生，后续周期仍保留。
- 网页 Demo 提供默认关闭的网页内到期弹窗开关：开启后仅在页面打开时对当前海缸当天待办自动显示一次，可进入当天任务或选择当天不再提示。浏览器关闭后的 Android/iOS 系统通知仍属于 Flutter App 与真机验收范围。
- 新任务的默认提醒时间为上午 09:00，用户可以修改。
- 任务到期时通过 Android/iOS 系统通知栏显示本地通知。
- 点击通知后进入对应任务；App 内仍保留待办状态，不能仅因通知已展示而自动完成。
- 任务完成后记录实际完成时间；重复任务从实际完成时间起计算下一次到期时间。
- 任务逾期后保持逾期状态，并在每天上午 09:00 再次提醒，直到用户完成、跳过或停用该任务。
- 任务详情提供“完成”“稍后提醒”“跳过”三个操作。
- 稍后提醒默认选项为 1 小时后、明天 09:00 或自定义时间，不改变原重复周期。
- 跳过会记录一次跳过事件，并从跳过时间起计算下一次到期时间。
- 停用任务会取消未来通知并保留历史；删除任务需要二次确认。

通知权限被拒绝、通知被用户关闭、设备关机或系统延迟时，App 仍应在任务列表中显示到期/逾期状态。各平台能够保证的通知时效待真机验证。

## 设置

- 添加、重命名、切换和管理海缸。
- 设置每个海缸所有已启用参数的目标范围。
- 目标范围按 `海缸 + 指标` 独立保存；切换海缸后首页状态、趋势目标带和建议立即使用该海缸的范围。
- 目标上下限允许随时修改，必须为非负数且下限不得大于上限；新海缸默认不预填所谓通用最佳值并提示用户设置。
- 查看并管理通知权限状态。
- 深色/浅色主题选择需要持久化，并随完整业务数据备份迁移；系统主题和通知权限等操作系统状态不由备份覆盖。
- 导出不含照片的完整业务数据备份，覆盖海缸、参数及启停、目标、试剂、当前海缸、检测记录/趋势来源、维护任务和历史、计时默认及未完成草稿。
- 恢复先完成 ZIP、SHA-256、版本和关联校验，再二次确认并以备份为准替换本机业务数据；系统通知权限不迁移，维护提醒按本机权限重新安排。
- 导出检测记录 CSV 作为便于查看的附加能力，不用于完整恢复。
- 默认不提供账号、云同步、社交分享或在线专家诊断。

### 网页版 Demo：氯化镧理论计划（不属于 Flutter MVP 已实现能力）

- 用户输入最近复测并人工确认的 PO4 单值、目标 PO4 和海缸实际净水体积；范围型或未确认记录不得直接驱动计划。
- Demo 固定采用纯度 `99.9%` 的七水合氯化镧 `LaCl3·7H2O`。它依据 `La3+ + PO4^3- -> LaPO4` 的 `1:1` 摩尔关系计算理论质量，不提供反应效率系数，也不因实际下降不足自动增加质量。
- 母液强度固定为每 `1 mL` 理论处理 `10 mg PO4`，即让 `100 L` 水体降低 `0.1 mg/L`。网页版允许选择母液最终体积：默认 `500 mL` 时称取 `19.571329 g` 七水合氯化镧，其他体积按比例缩放；Flutter App 当前仍固定为 `500 mL`。“定容至所选最终体积”不能显示成“向同体积水中加入”。
- 实际净水体积输入默认 `200 L`；精确目标不得低于 `0.03 mg/L`；计划单日最大降幅输入限制为 `0.1–0.5 mg/L`。该范围不得称为系统验证的通用安全范围。
- 每日计划降幅不超过用户输入上限，最后一日只处理剩余差值；母液量按 `当日计划降幅 × 净水体积 ÷ 10` 计算，之后定容成最终 `500 mL` 工作液。确认计划后，系统严格按计算出的预计天数，从当天起逐日创建有限数量的任务，直到理论计划达到目标值；事项必须显示“先测 PO4/KH 并观察生物、达到目标或异常即停止”，且停止某一日时同步停止同一计划当天及后续事项。
- 简化界面不再要求检测可靠下限、日降幅依据或安全复选框，但必须继续提示机械过滤或蛋分捕获沉淀、每日复测和异常停止。
- 该原型不自动投药、不控制硬件、不替代产品标签/SDS 或专业判断；公式、来源和操作边界见 `docs/LANTHANUM_CHLORIDE_CALCULATOR.md`。

### 网页版 Demo：海盐配制计算器（不属于 Flutter MVP 已实现能力）

- 设置页提供海盐配制计算器，初始比重默认 `0`，目标比重默认 `1.025`，用户必须能填写起始水量并得到需要加入的海盐克数估算。
- 初始值 `0` 是 RO/DI 无盐水快捷输入，计算时按 `SG 1.000`；已有盐水可填写 `1.000–1.040`。目标必须高于初始值，当前不计算降低盐度的换水量。
- 品牌包装校准默认采用可编辑的 Red Sea Salt 示例 `38.2 g/L @ SG 1.0255`。结果按比重差比例估算，不能把示例值称为所有品牌通用精确用量。
- 结果同时显示总估算量、建议首次加入的 90% 和预留微调量；必须提示充分溶解、达到产品参考温度、使用校准量具复测，并避免在有生物的展示缸中直接混盐。
- 公式、来源和边界见 `docs/SALINITY_CALCULATOR.md`。

## 海缸管理

- 首次启动创建名为“我的海缸”的默认海缸，进入设置后可以重命名。
- 添加海缸只要求名称；备注为可选字段。
- 删除包含记录或任务的海缸前展示影响范围并二次确认；首版优先提供归档以避免误删。
- 切换海缸后，首页、趋势和任务均只展示当前海缸数据；开始检测时再次显示当前海缸名称。

## 水质状态与建议

- NO3、PO4 目标范围由用户按海缸设置；没有可靠来源前不预填所谓通用最佳值。
- 建议只基于用户最终确认值、用户目标范围和已保存历史，不基于未确认的拍照估值。
- 建议分为“低于目标、目标范围内、高于目标、变化过快、数据不足”。
- 每条常规维护建议显示触发条件、观察到的数据和建议动作，不自动控制设备、不推荐通用药剂剂量。网页版 Demo 中独立的氯化镧计算器只能给出有明确输入与来源的理论化学计量和用户确认后的分日计划，不属于一般建议，也不能称为安全剂量。
- 减少喂食、清洗滤棉、更换吸磷材料等动作以可选检查项呈现，并明确不能替代专业诊断。

## 空状态、权限和可恢复性

- 没有记录时展示“开始第一次检测”和“手动添加记录”，不显示虚构趋势。
- 通知或相机权限被拒绝时解释影响，并提供进入系统设置的入口，不阻断其他功能。
- 正在编辑表单或检测流程时离开页面需要保留草稿；明确放弃时才清除。
- 所有危险删除操作都需要二次确认；旧版本照片可单独删除并保留检测数值。
