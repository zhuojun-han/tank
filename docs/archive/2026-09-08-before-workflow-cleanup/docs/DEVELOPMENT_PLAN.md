# 开发与验收计划

本文件记录分阶段计划与验收门槛。阶段 0 的 Windows/Android 范围已于 2026-08-09 完成；完整跨平台验收仍待 macOS/iOS 启动验证。每阶段完成后必须更新 `docs/CURRENT_STATUS.md`，不得仅因代码已编写就标记完成。

## 阶段 0：工程初始化

- 创建 Flutter Android/iOS 工程，建立开发、测试和发布配置。
- 接入代码检查、单元测试和基本持续集成。
- 建立按功能分层的目录、主题、导航和错误日志接口。

验收：Android 与 iOS 模拟器/真机至少各完成一次启动验证；实际命令和结果届时写入项目文档。

当前结果：Android API 36 模拟器启动、APK 安装和应用启动已通过；iOS 待 macOS/Xcode 环境确认，因此完整跨平台阶段 0 尚未关闭。

## 阶段 1：本地数据与海缸

- 实现数据库、迁移、默认海缸、多海缸切换和归档。
- 实现目标范围、试剂配置和仓库层。
- 实现内置参数、每缸启用关系和自定义参数；KH、Ca、Mg、K不得被强制启用。
- 实现本地备份/恢复的最小版本。

验收：首次启动只有一个默认海缸；KH、Ca、Mg、K可按海缸独立启用/停用；自定义参数创建后进入检测、目标、历史和趋势；停用不删除历史；新增/切换后数据和目标范围不串缸；修改后首页、趋势和建议立即刷新；备份恢复不丢失记录关联。

## 阶段 2：手动检测与趋势

- 实现 NO3/PO4 手动录入、范围型结果、照片临时辅助处理和记录编辑。
- 实现趋势图、目标区间、空状态和数据不足提示。
- 实现规则建议框架，但不内置无来源阈值。

验收：单档与范围均能保存；保存后的 NO3/PO4 记录可以修改海缸、指标、时间、最终数值/范围和备注；算法原始估值不被覆盖；修改后首页、趋势和建议立即刷新；当次照片确认或取消后删除且不影响数值；少于两条记录不显示趋势判断；建议能展示触发数据和规则来源。

## 阶段 3：任务与通知

- 实现任务增删改停用、完成/稍后提醒/跳过和历史事件。
- 实现到期通知、每日逾期提醒、权限引导和启动时通知重算。

验收：默认 09:00；完成/跳过从操作时间计算下一周期；稍后提醒不改变周期；停用取消未来通知；权限拒绝时 App 内状态仍正确。

## 阶段 4：检测计时器与拍照

- 实现 5 分钟初始计时、3/5/10 分钟快捷选择、按海缸与参数保存的 10 秒至 60 分钟自定义默认时长、后台恢复、结束通知和检测草稿。
- 实现拍摄引导、权限降级、照片压缩和质量检查。
- 先提供人工选择色卡档位，确保算法未完成时流程仍可用。

验收：快捷与自定义时长均可启动并在后续检测复用；不同海缸和参数的默认时长互不影响；计时开始后不能误改时长，重置后可重新设置；切后台、杀进程后依据结束时间恢复；结束通知可返回正确检测；相机不可用时可手动完成；放弃草稿不会产生正式记录。

## 阶段 5：NO3 辅助估值

- 实现色卡/试管定位、颜色校正、距离计算、范围输出和拒绝机制。
- 建立版本化样本清单和离线评估脚本。
- 达到经样本确定的发布阈值前保留“实验性”标识。

验收：固定验证集可重复得到同样结果；低质量图片被拒绝；算法输出不会覆盖人工确认值；报告包含所有指标而非只展示成功案例。

## 阶段 6：PO4 与发布准备

- 在取得 PO4 试剂资料和样本后新增独立配置与验证。
- 完成可访问性、中文文案、隐私说明、存储空间和权限测试。
- 完成 Android/iOS 真机回归、备份恢复演练和发布检查。

验收：两个平台核心流程通过；无网络仍可使用；照片不离开设备并在当次比色后清理；已知限制在 App 和发布说明中可见。

## 关键测试集合

- 数据：迁移、事务回滚、跨海缸隔离、范围校验、时区变化、完整快照恢复与旧备份兼容。
- 通知：权限允许/拒绝、设备重启、时区变化、逾期、停用、完成、跳过、稍后提醒。
- 检测：计时恢复、相机拒绝、空间不足、临时照片清理、保存前修正、历史记录编辑、跨海缸/指标修改后的趋势刷新、草稿放弃。
- 图像：模糊、过曝、遮挡、缺色卡、强反光、有色灯、相邻档位和不支持色卡。
- 体验：首次使用、空数据、单手操作、较大字体、深色模式和危险操作二次确认。
