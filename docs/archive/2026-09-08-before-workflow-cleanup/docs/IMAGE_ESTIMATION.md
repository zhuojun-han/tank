# 拍照估值规范

## 目标与输出

首版对测试液和同画面完整色卡进行端侧辅助比色。输出只能是：

- 单个色卡档位；或
- 两个相邻档位构成的范围；或
- 无法估值并给出重拍/手动录入原因。

结果必须附带内部质量评分，并在界面映射为高、中、低置信度。置信度阈值需由验证集确定，当前待确认。

## 拍摄流程

- 后置主摄、关闭闪光灯，锁定竖屏拍摄。
- 画面辅助框要求完整色卡和试管均入镜，试管不得遮挡色块或数字。
- 色卡与试管放在同一中性浅色背景上，相机尽量垂直，避免手持遮挡、强反光、阴影和有色灯光。
- 固定试管、液量、色卡版本及显色时间；试剂过期或色卡严重污损时提示不能保证结果。
- 拍照后允许裁切校正，但不得使用会改变颜色的美化滤镜。

## 处理管线

1. 检查图像尺寸、模糊、过曝/欠曝和色卡是否完整。
2. 定位色卡外框、色块、数值标签和试管有效液体区域。
3. 做透视校正，并排除色块边缘、文字、试管高光、气泡和液面。
4. 使用色卡白底/中性区域做同图颜色校正。
5. 在 Lab 等感知颜色空间计算测试液与各色块的稳健统计距离。
6. 综合最近与次近档位距离、区域颜色方差及图像质量生成置信度。
7. 最近档位不明显时输出相邻范围；质量不合格或结果矛盾时拒绝估值。
8. 保存算法版本、估值范围、置信度和用户最终确认值。

大模型不参与首版数值判断。若规则定位在真实设备上不稳定，可训练小型端侧模型定位色卡/试管区域，但最终颜色比较仍使用可解释算法。

## 当前资料

- 试剂：益尔 NO3。
- 单位与档位：0、1、5、10、25、50、100 mg/L。
- 当前带标签样本：一张，人工结果为 10–25 mg/L。历史记录提到一次初步像素比较也落在该范围，但当前仓库没有可复现的区域标注和运行输出，需重新验证。
- 当前结论只能登记这张样本的人工标签，不能据此计算准确率、确定误差或验证算法判断。
- PO4 品牌、色卡、显色时间和样本：待确认。

## 数据集与验证要求

- 每个试剂档位需要多份独立测试液，而不是只重复拍同一管液体。
- 覆盖至少多台 Android 和 iPhone、室内自然光与常见白光、轻微角度和距离变化。
- 每张照片记录试剂品牌/批次、色卡版本、人工标签、设备、光照和拍摄时间。
- 训练/调参集与最终验证集按测试液批次隔离，避免同一液体泄漏到两边。
- 同时统计：可估值率、正确档位率、正确相邻范围覆盖率、严重跨档错误率和拒绝率。
- 发布阈值必须在取得样本后由实际测试确定；样本不足时拍照功能只能标为实验性或不发布。

## 失败提示

- 色卡未完整入镜。
- 试管遮挡色块或液体区域不可见。
- 图片模糊、过曝、过暗或反光过强。
- 颜色校正失败或检测到疑似有色光源。
- 最近档位差异不足，建议重新拍摄或人工选择范围。
- 当前试剂/色卡版本不受支持。
