# NO3 离线辅助估值评估 V0

## 结论

当前没有足够的独立、按批次标注样本，无法计算准确率、覆盖率、严重跨档错误率或可估值率。现有代码仅是可解释的实验性算法骨架，不应作为已验证的水质数值判断，也不得宣传确定误差或实验室级精度。

## 数据清单

- 清单版本：`datasets/no3/manifest_v1.json`
- 已登记同框照片：1 张
- 可进入最终验证集：0 张
- 已知人工标签：10–25 mg/L
- 缺失信息：独立测试液批次、试剂批号、色卡版本、设备、光照、拍摄时间和区域标注

## 已实现的离线规则骨架

以下能力只处理调用方预先提取的颜色与质量指标；目前尚未实现从整张照片自动定位色卡、试管区域或计算清晰度、曝光等指标，因此不是端到端图片算法。

- 对预提取的同图中性区域颜色执行校正，并拒绝过暗或明显偏色的参考输入。
- sRGB 转 CIE Lab，并使用 Delta E 76 做可解释距离比较。
- 仅输出色卡单档、相邻档位范围，或带原因的“无法估值”。
- 对调用方提供的分辨率、模糊、过暗、过曝、强反光、色卡完整性和液体可见性指标执行拒绝规则。
- 保存算法版本、质量评分、置信度及各档距离所需的数据结构。
- 评估统计强制计入拒绝和严重跨档错误，分别统计单档正确率与相邻范围覆盖率，并审计调参与验证批次隔离。

当前阈值是工程占位值，尚未由验证集拟合，置信度“高/中/低”也不能解释为已测准确概率。

## 进入真实评估前的门槛

1. 每个档位采集多份独立测试液，记录批次并按批次隔离调参与验证集。
2. 覆盖多台 Android 与 iPhone、常见白光和自然光、轻微角度与距离变化。
3. 标注完整色卡、各色块、中性区、试管液体有效区，并记录排除原因。
4. 冻结算法版本和阈值后一次性跑完整验证集，报告所有成功、拒绝和错误案例。
5. 只有真实结果满足后续明确设定的发布门槛，才可改变“实验性辅助估算”的表述。
