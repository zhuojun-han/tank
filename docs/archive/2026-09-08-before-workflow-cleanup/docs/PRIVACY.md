# 隐私说明

## 数据处理边界

澜礁水质助手首版采用离线优先设计，不要求注册账号，不提供云同步，也不把海缸资料、检测结果或照片上传到项目方服务器或第三方视觉服务。

以下数据保存在 App 私有目录或本地 SQLite 数据库中：

- 海缸、参数、目标范围、试剂配置；
- 用户最终确认的检测结果与备注；
- 实验性辅助估值、质量检查和人工复核元数据；检测照片仅在当次比色时进入应用缓存，确认或取消后删除；
- 维护任务、处理历史、检测草稿和计时默认值；
- 用户主动创建的本地备份。

系统相机仅用于用户主动发起的检测拍照。相机控制器禁用录音；iOS 平台配置中的麦克风用途说明是当前 Flutter 官方相机插件安装要求，首版业务不会录制音频或视频。

系统通知仅用于本机维护任务和检测计时结束提醒。通知内容可能显示任务名称；用户可拒绝通知权限，拒绝不会阻止 App 内记录、任务或计时状态工作。

## 用户控制

- 用户可不拍照，直接手动录入检测结果。
- 新检测不会长期保存照片；旧版本已经留档的照片仍可单独删除并保留检测数值。
- 用户可停用或归档维护任务并保留历史。
- 用户可主动创建、导出或恢复不含照片的完整业务数据备份；备份一旦被复制或分享至其他位置，其保管和访问权限由该位置决定。系统通知权限属于设备状态，不进入备份。
- 卸载 App 通常会删除应用私有数据；平台备份策略和用户导出的文件不一定随卸载删除。

## 不处理的内容

首版不包含账号、广告、分析 SDK、远程诊断、社交分享、自动加药或硬件控制。若后续增加任何联网或第三方数据处理能力，必须在启用前更新本说明并取得必要授权。

## 安全与诊断边界

拍照输出只能作为辅助估算，用户最终确认值才进入后续建议。维护建议不能替代规范复测、专业诊断或对缸内生物的持续观察，App 不提供具体药剂剂量。
