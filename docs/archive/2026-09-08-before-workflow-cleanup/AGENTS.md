# Codex 项目规则

- 开始工作前先阅读 `README.md`、`docs/PROJECT_CONTEXT.md` 和 `docs/CURRENT_STATUS.md`。
- 以源代码、配置文件、报告和测试结果作为项目事实依据。
- 不得编造功能、指标、命令或验证结果。
- 不确定的信息标记为“待确认”。
- 保留用户已有修改，不覆盖无关内容。
- 完成修改后运行适用的验证。
- 长任务交付前重新核对本文件。
- 完成重要工作后更新 `docs/CURRENT_STATUS.md`。
- 尚无工程配置时，不得编造运行、构建或测试命令。
- 水质拍照结果只能描述为辅助估算；未经真实样本验证，不得宣称实验室级精度或确定误差范围。
- 水质维护建议必须有可追溯的规则依据，并明确不能替代专业诊断。
- 修改功能或项目状态时，同步核对 `README.md`、`docs/PROJECT_CONTEXT.md` 和 `docs/CURRENT_STATUS.md`，避免相互矛盾。
