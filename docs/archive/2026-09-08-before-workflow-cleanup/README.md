## 网页版 Demo

`web-demo/` 是用于验证手机端交互流程的响应式网页版原型，包含首页、检测、趋势、任务日历、设置和多海缸管理。首页最上方提供按当前海缸独立保存的养鱼模拟器；点击鱼缸可从内置目录选择小丑鱼、双斑宝石海金鱼公/母、蓝眼海金鱼公、深水樱花宝石、火焰仙、紫吊、粉蓝吊和东非金剪刀，并设置数量、入缸日期，也可新增其他鱼种并上传自己的立绘。内置目录使用已选定的轻写实动画透明素材，鱼缸使用用户选定的自然珊瑚礁背景；自定义立绘会在浏览器内缩放压缩后保存到当前海缸，不上传云端，并直接用于鱼缸中的游动图像。鱼按带上下漂移的二维轨迹游动，可使用除约 4 px 安全边距外的完整可见水域；除临近四壁时平滑减速转向外，也会间隔约 8–16 秒在开阔水域随机换向，鱼头始终随水平速度改变朝向。首页其余部分按设备当天日期展示当前海缸概览，并依据最近检测结果与用户目标范围生成有规则来源的 NO3/PO4 日常维护建议；随后显示未完成事项和各参数趋势摘要。任务页提供按真实年月排列、可前后翻月和按日查看事项的月历；选中日期后，每条当天待办都显示独立的“完成本次”和“跳过本次”按钮。普通周期任务只保存一条重复规则，并只对当前可见的六周动态计算日期，不会预先生成无限任务；每次完成/跳过记录只作用于所选日期。用户可选择开启网页内到期弹窗，同一天自动提示一次并可进入当天任务；该提示仅在网页打开时生效，不等同于浏览器关闭后的手机系统通知。

Demo 与 Flutter App 均提供实验性的氯化镧降低 PO4 理论计算与分日待办：固定使用纯度 `99.9%` 的七水合氯化镧 `LaCl3·7H2O`；网页允许选择母液最终体积，默认 `500 mL` 时称取 `19.571329 g`，改变体积只按比例改变称取质量，不改变每 `1 mL` 理论处理 `10 mg PO4` 的强度。Flutter App 已同步可选母液体积与所需批数。计算器默认实际净水体积 `200 L`，精确目标不得低于 `0.03 mg/L`，计划单日最大降幅限制为用户指定的 `0.1–0.5 mg/L`。系统按 `La3+ + PO4^3- -> LaPO4` 的 `1:1` 摩尔关系计算且不做反应效率补偿；确认计划后会把全部分日事项按当天起连续日期加入任务月历，但每一项都明确要求当天先复测、观察生物再决定是否执行，停止任一日会同时停止该日及后续计划。该范围不能称为通用安全剂量，也不自动投药；完整公式、来源和停止条件见 [计算器说明](../../LANTHANUM_CHLORIDE_CALCULATOR.md)。

网页版与 Flutter App 设置页均有碳酸氢钠提升 KH 理论计划：按 `NaHCO3` 的一价碱度当量计算，`100 L` 提升 `1 dKH` 理论需要约 `3.00025 g` 纯品。每日 KH 消耗默认 `0.5 dKH`，每日投加当量由“计划净升幅 + 消耗补偿”组成并分别显示。母液体积可选，强度按每 `100 L` 提升 `0.1 dKH` 所需整数毫升数设置（网页版与 Flutter 均为 `4/6/8/10 mL`）；默认 6 mL 档约为 `50.004 g/L`，并按用户输入的 `0–40°C` 最低温度检查溶解度和 20% 程序余量。结果按有限天数写入任务月历，每天仍要求先复测 KH/pH 并重算。该功能已同步 Flutter App，结果不代表真实海缸的精确或通用安全剂量；完整公式和来源见 [碳酸氢钠 KH 计划说明](../../SODIUM_BICARBONATE_KH_CALCULATOR.md)。

设置页另有海盐配制计算器：初始比重默认 `0`（表示 RO/DI 无盐水，计算时按 `SG 1.000` 起点处理），目标比重默认 `1.025`，用户填写起始水量和实际海盐包装标注的每升用盐量及对应比重后得到克数估算。默认 `38.2 g/L @ SG 1.0255` 只是可编辑的 Red Sea Salt 示例；不同品牌、温度和量具会改变实测值，结果要求先加约 90%、充分溶解后复测微调。完整公式和来源见 [海盐配制计算器说明](../../SALINITY_CALCULATOR.md)。

Demo 使用浏览器本地存储和模拟通知/识别流程，只能证明原型交互；Flutter App、系统通知和拍照辅助流程的实际状态以源码、测试及 `docs/CURRENT_STATUS.md` 为准。

网页版两种加药计划在当前海缸的新计划开始日及以后已有同类计划时，会用网页内对话框询问是否覆盖：确定后只删除并替换开始日及以后的同类旧任务，更早日期的旧计划、完成状态和历史记录保留；取消则保留原计划。加载已有浏览器数据时同样只清理被更新计划日期范围覆盖的旧任务；其他海缸、另一种药剂和普通周期任务不变。新输入校验通过后才询问，不因计算失败删除旧计划。

网页版首页仅展示当前海缸本日未完成事项，不列出过去或未来日期的待办；KH、PO4 同一加药计划在首页及任务页“待处理”中各合为一项，待处理计数也按合并项计算。“计划与本日记录”中的加药总计划只提供“查看每日安排”和“停止后续计划”，查看时用页内详情完整展示该计划全部日期、状态和任务说明；当天操作保留在日历详情。日历任务卡折叠长说明并区分主次操作：完成按钮独占一行，稍后与停止/跳过并排，已完成状态与恢复按钮紧凑排列。用户添加的“每 N 天”周期任务可选择过去、今天或未来的开始日期；过去的开始日期会把今天之前符合间隔的执行日默认为已完成，并允许逐日恢复为未完成。周期任务卡右上角的“•••”可编辑名称、开始日期、提醒时间和重复间隔；保存会更新原规则并保留已有逐日完成/跳过记录。周期规则不进入“待处理”、只在“全部”展示，实际发生日仍进入首页和日历待办。“稍后 1 小时”保存精确到期时间并只影响当天；到期后自动恢复待办，开启网页提醒且页面打开时会再次弹窗，网页重新打开时也会结算已到期状态。跳过或停止后的事项不再出现在日历日期格和“当天待办”，后续日期也会隐藏，但处理记录仍保留在浏览器数据中。任务页“已完成”只展示本日已完成事项；“全部”只展示仍在运行的周期任务规则，以及仍有未完成天数的 KH/PO4 加药总计划，已停止周期不显示。

## MVP 目标

MVP 范围包含水质检测、维护提醒和海缸管理：

### 1. 水质检测

- 实验性 NO3 拍照流程给出辅助比色估算；PO4 及其他参数须具备试剂资料和真实样本验证后才开放拍照估值。
- 拍照文件只在本机缓存中服务于当次人工比色，确认或取消后删除；长期记录只保留数值、拍摄时间和必要的质量/复核元数据。
- 内置 NO3、PO4、KH、Ca、Mg、K；用户可按海缸选择启用 KH、Ca、Mg、K，并可自行命名和添加其他水质参数。
- 所有启用参数均支持手动检测记录、独立目标范围、历史编辑和趋势；拍照估值仅对具备试剂资料与样本验证的参数开放。
- 记录检测时间、指标、估算值及用户最终确认值。
- 展示历史数据和水质变化趋势。
- 允许用户设置各项水质指标的期望范围。
- 根据当前数值、目标范围和变化趋势提供规则化建议，例如减少喂食、清洗滤棉或更换吸磷材料。
- 提供与检测流程放在一起的短时计时器；用户为某海缸的某项参数自定义时间后，后续检测继续使用该默认时长，直到再次修改。

> 拍照识别结果仅作为辅助估算，不能替代规范的人工比色、仪器检测或专业判断。估值能力、误差范围和适用条件需经真实色卡与样本验证后确定。

### 2. 维护任务提醒

- 用户可以自行添加、编辑和停用维护任务。
- 每项任务可以自定义重复间隔。
- 到期时通过 Android/iOS 系统通知栏弹出本地通知，并记录完成时间。
- 示例任务包括每两周换水、每三天更换或清洗滤棉，以及定期更换活性炭、吸磷材料。

维护任务提醒与水质检测计时器是两个独立模块：前者用于跨天或周期性维护，后者服务于一次水质检测过程中的短时间等待。

### 3. 海缸管理

- 首次使用时默认创建一个海缸。
- 用户可以继续添加多个海缸。
- 水质记录、目标范围和维护任务均归属于指定海缸。

## 分步任务

当前实现与验收路线如下；“已实现”不等于已经完成真机、真实样本或发布验收：

1. **需求确认（已完成）**：确定目标用户、首版范围、支持平台、指标单位、提醒行为和数据保存需求。
2. **原型与数据设计（已完成）**：设计主要页面、检测流程、任务流程以及本地数据模型。
3. **基础记录功能（已实现并通过自动化测试）**：NO3/PO4 等启用参数的手动录入、修正、历史记录、期望范围和本地数据管理。
4. **提醒模块（已实现，待真机验收）**：自定义任务、重复间隔、到期提醒、稍后提醒和完成/跳过记录。
5. **拍照估值（实验性 NO3 流程已实现，待样本验收）**：仍需完善真实色卡/样本、颜色校准和独立评估后才能确定适用范围。
6. **趋势与建议（已实现并通过自动化测试）**：趋势展示和具备规则来源、安全边界的 NO3/PO4 建议。
7. **测试与发布（进行中）**：自动化测试与 Android 模拟器 debug 验收已完成；算法样本、真机权限/通知、iOS 和发布准备仍待完成。
