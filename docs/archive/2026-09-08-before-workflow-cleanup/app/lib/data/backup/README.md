# 备份层

当前已实现三类本地数据传输：

- `LocalBackupService` 生成 v9 JSON 业务数据快照，并兼容读取 v1–v8；新旧格式恢复时都会剥离检测记录和未完成草稿中的照片路径，同时清空设备派生的通知 ID。
- `CompleteBackupService` 把 JSON 与 SHA-256 完整性清单打包成 ZIP。新备份只含 `database.json` 与 `manifest.json`，不含照片；历史 ZIP 中的照片仍参与完整性校验，但不会复制到新设备。
- `TestRecordCsvExportService` 按海缸导出便于查看的检测记录 CSV；CSV 不是恢复格式。

设置页使用权威恢复：完成 ZIP、版本、字段和关联校验并经用户二次确认后，在同一 SQLite 事务中以备份为准替换全部 11 张业务表，包括当前海缸和主题模式。维护任务通知权限不随备份迁移，数据库提交后由本机通知协调器重新安排。

新周期任务的开始日期、默认历史完成边界、逐日完成/跳过/恢复、稍后截止和停止边界随 recurrenceJson 保存并校验。旧任务的空字段保持原推进语义，不推测原始开始日期。
