# 已知限制

本文件维护长期验证边界；本轮缺陷和待同步功能见 [当前状态](CURRENT_STATUS.md)。

## 拍照辅助估算

- NO3/PO4 已提供色卡和多张样本并有本地模板比色功能；样本批次、真值和设备/光照覆盖仍不足以证明浓度精度。
- 当前用户旋转并框选完整色卡及测试液，程序在固定八块模板内取色。没有通用 OCR、任意色卡/试管自动定位、完整透视和跨设备颜色/浓度校准。
- 光照、白平衡、反光、液量、显色时间、试剂批次和色卡老化都可能改变结果；质量拒绝不能发现所有坏照片。
- 最近档、候选范围、插值独立判断，不应把候选范围解释为测量误差，或把工程阈值解释为准确概率。用户可修改后选择是否记录；具体合同见 [拍照规范](IMAGE_ESTIMATION.md)。

## 提醒与运行

- 网页提醒仅网页打开时生效；没有关闭后的手机系统通知。补液周期根据输入泵量和日历估计，不读取真实泵运行或残液。
- App 通知受授权、设备关机、省电和平台调度影响；新日期周期预排近两次发生日，操作/打开/恢复时补排，不具备无限后台补排保证。
- Android 精确闹钟未获授权时检测计时通知可降级，维护任务默认非精确；通知显示不代表任务已完成。
- 相机、通知栏、厂商后台策略、真实文件分享/低存储及 iOS 须在对应真实设备验证，模拟器或单元测试不能替代。

## 数据与发布

- 无账号云同步。App 本地备份是用户主动快照；网页 localStorage 与 App 备份不通用，清理浏览器数据或遗失设备可能造成无法恢复。
- App 恢复经校验和确认后按备份替换业务数据；照片与设备权限不迁移。实际合同见 [技术设计](TECHNICAL_DESIGN.md)。
- 时间点按设备时区显示，周期保持本地日历日期语义；换时区需核对提醒。
- Windows 不能完成 iOS 构建或设备验收；正式签名、商店信息、原生库兼容性和真机要求见 [发布清单](RELEASE_CHECKLIST.md)。
